# CHANGELOG

## v0.4

- Утверждён компактный формат реестра требований.
- Длинные составные идентификаторы заменены короткими ID.
- Введены категории GAME, MATCH, ARMY, COMBAT, AI, MORALE, ECON, PROG, MON, TECH, NET, DATA, PERF, TEST.
- Разделены статус принятия требования и статус реализации.
- Требования собраны в едином реестре `REQUIREMENTS.md`.
- Документация переработана по игровым и техническим подсистемам.

## v0.3

Предыдущая редакция документации. Использовала избыточную систему идентификаторов и заменена v0.4.

## Правила ведения изменений

1. Не менять ID существующего требования при редактировании формулировки.
2. Не переиспользовать ID удалённых требований.
3. Новому требованию выдавать следующий свободный номер соответствующей категории.
4. Изменения принятых решений отражать в CHANGELOG.
5. Не смешивать статус принятия требования со статусом реализации.
