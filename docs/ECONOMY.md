# Экономика матча

## 1. Общая система

В матче используется командный ресурс, необходимый для развёртывания подразделений.

Ресурс поступает из трёх источников одновременно.

## 2. Источники ресурса

### Периодический доход

Команда получает ресурс через равные интервалы времени.

### Контрольные точки

Удержание контрольных точек приносит дополнительный ресурс.

### Уничтожение врагов

Уничтожение противников приносит ресурс команде.

## 3. Расходы

Основной расход — развёртывание отрядов.

Стоимость каждого типа войск должна зависеть от его силы и роли.

## 4. Развёртывание

Если ресурса хватает на несколько отрядов, игрок может развернуть их подряд.

Искусственной задержки между стандартными развёртываниями нет.

## 5. Пополнение

Пополнение бойцов разрешено только в удалённом лагере.

## 6. Нулевой ресурс

Предполагается бесплатное крестьянское ополчение.

Требуется определить:

- численность;
- характеристики;
- лимит;
- условия получения;
- возможность повторного получения.

## 7. Параметры балансировки

Пока не утверждены:

- начальный запас ресурса;
- стоимость каждого отряда;
- интервал периодического дохода;
- объём периодического дохода;
- доход за контрольные точки;
- награда за убийства;
- лимит активных отрядов;
- ограничения бесплатного ополчения.

Эти параметры необходимо определить после первых игровых тестов.
