# Армии и отряды

## 1. Общие принципы

Игрок заранее собирает конфигурацию армии.

Состав армии фиксируется в начале матча. Изменять его можно между матчами.

Игрок управляет подразделениями как едиными отрядами. Индивидуальные приказы каждому бойцу отсутствуют.

## 2. Максимальная численность отрядов

| Тип войск                        | Максимум бойцов |
| -------------------------------- | --------------- |
| Лёгкая пехота                    | 30              |
| Тяжёлая пехота                   | 24              |
| Лучники/стрелки                  | 24              |
| Лёгкая кавалерия                 | 15              |
| Тяжёлая кавалерия                | 10              |
| Редкие/специализированные войска | 4               |

Указанные значения — верхние пределы. Отряд не обязан всегда развёртываться в максимальном составе.

## 3. Здоровье бойцов

У каждого бойца индивидуальный запас HP.

Смерть отдельного бойца уменьшает численность отряда.

Мораль рассчитывается на уровне всего отряда.

## 4. Уничтожение отряда

Если все бойцы отряда погибают:

- отряд считается уничтоженным;
- его объект удаляется из активной симуляции;
- игрок получает возможность повторного развёртывания после установленного времени ожидания.

Минимальное время ожидания — 60 секунд.

## 5. Развёртывание

Игрок может развёртывать несколько отрядов подряд, если хватает ресурса.

Искусственной задержки между стандартными развёртываниями нет.

Развёртывание должно учитывать:

- доступность отряда;
- стоимость;
- время повторного развёртывания;
- ограничения состава армии;
- состояние матча.

## 6. Пополнение

Пополнение бойцов возможно только в удалённом лагере.

Пополнение вблизи линии боя не допускается.

## 7. Крестьянское ополчение

При нехватке ресурса предполагается возможность получить бесплатный отряд крестьянского ополчения.

Механика требует уточнения:

- численность;
- характеристики;
- доступность;
- ограничения повторного получения;
- возможность иметь несколько таких отрядов.

## 8. Открытые решения

- Максимум одновременно активных отрядов на игрока.
- Стоимость каждого типа войск.
- Начальный состав армии.
- Ограничения на повторное развёртывание помимо таймера.
- Правила бесплатного ополчения.
