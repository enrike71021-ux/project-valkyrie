# Сохранение данных

## 1. Сохраняемые данные

Предполагается сохранять:

- уровень аккаунта;
- общий прогресс;
- прогресс исследований по типам юнитов;
- открытые культуры;
- открытые юниты;
- доктрины;
- конфигурации армии;
- внутриигровую валюту;
- косметические предметы;
- права владения предметами.

Точная структура профиля должна быть определена до полноценной реализации системы сохранения.

## 2. Надёжность

При работе с DataStore необходимо:

- обрабатывать ошибки;
- использовать повторные попытки с задержками;
- ограничивать количество повторов;
- корректно завершать сохранение при закрытии сервера;
- использовать `BindToClose`;
- не считать ошибочный запрос успешным сохранением;
- предусмотреть версионирование данных.

## 3. Защита данных

Клиент не может напрямую менять сохранённые значения.

Валюта, прогресс, покупки и конфигурации проверяются сервером.

## 4. Открытые решения

- Полная схема профиля.
- Стратегия блокировки профиля.
- Политика повторных попыток.
- Миграции версий.
- Поведение при повреждении данных.
- Периодичность сохранения.
- Обработка конфликтующих записей.
