# Реестр требований VALKYRIE

Версия: 0.4

## 1. Статусы

### Статус требования

| Статус             | Значение                                         |
| ------------------ | ------------------------------------------------ |
| Зафиксировано      | Решение принято                                  |
| Требует уточнения  | Направление принято, детали открыты              |
| Предположение      | Рассматриваемый вариант, решение не принято      |
| Целевой показатель | Желаемый результат, который необходимо проверить |
| Отменено           | Решение больше не действует                      |

### Статус реализации

| Статус              | Значение                |
| ------------------- | ----------------------- |
| Не реализовано      | Работа ещё не выполнена |
| В разработке        | Работа выполняется      |
| Реализовано         | Функция создана         |
| Проверено           | Функция протестирована  |
| Требует исправления | Обнаружены проблемы     |

Статус реализации не заменяет статус требования.
